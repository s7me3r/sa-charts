## Download

1. Go to **[Releases → Latest](https://github.com/s7me3r/sa-charts/releases/latest)**.
2. Download **`SA-Charts-Setup.exe`** and run it. No admin rights needed.
3. Open **SA Charts** from the desktop or Start menu.

SA Charts updates itself. When a new version is out you'll see **Install & restart** in the bottom bar.

> Windows may show "Windows protected your PC" for new apps. Click **More info → Run anyway**.

## Features

| | |
|---|---|
| **Markets** | Every Bybit USDT perpetual + gold (XAUUSD, Bybit + Binance index) |
| **Timeframes** | 1m, 3m, 5m, 15m, 30m, 1h, 2h, 4h, 6h, 12h, 1D, 1W, 1M |

## Keyboard shortcuts

| Keys | Action |
|---|---|
| Type any letter | Search symbol |
| Alt + H | Horizontal line |
| Alt + A | Alert at cursor |
| Alt + T / F / R / V | Trend line / Fib / Zone / Vertical line |
| Alt + X | Reset chart view |
| Shift + drag | Measure |
| Ctrl + Z / Y | Undo / Redo |
| Ctrl + C / V | Copy / paste drawing |
| Delete | Delete selected drawing |
| Right-click | Chart menu (stops a drawing tool) |

## FAQ

**Is my money or exchange account connected?**
No. SA Charts is charts only. It never asks for exchange keys or funds.

**Where does the data come from?**
Public market data from Bybit, and Binance for gold. Your app connects to them directly.

**Is gold the real price?**
Gold is the spot index from Bybit and Binance. It's usually within a few dollars of broker XAUUSD; small differences between brokers are normal.
